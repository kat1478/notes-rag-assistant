BFS (breadth-first search) and DFS (depth-first search) are the two basic ways to traverse a graph. BFS explores the graph level by level: first all neighbors of the start node, then their neighbors, and so on. It uses a queue (first in, first out). Because it reaches nodes in order of the number of edges from the start, BFS finds the shortest path in an unweighted graph. DFS goes as deep as possible along one branch before backtracking. It uses a stack, either an explicit one or the call stack when written recursively. DFS is the natural choice for detecting cycles, finding connected components and topological sorting: in a directed acyclic graph, ordering the nodes by decreasing DFS finish time gives a valid topological order, which is how build systems decide in which order to compile dependencies. Both algorithms run in O(V + E) time with an adjacency list, where V is the number of vertices and E the number of edges. Both need to mark visited nodes, otherwise they can loop forever in a graph with cycles. Memory differs: BFS may have to store a whole level of the graph in its queue, while DFS only stores the current path.
