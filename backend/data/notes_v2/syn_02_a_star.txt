A* (A-star) is a best-first search algorithm for finding the shortest path from a start node to a single goal node. For every node it computes f(n) = g(n) + h(n), where g(n) is the real cost from the start to n and h(n) is a heuristic estimate of the remaining cost from n to the goal. The algorithm always expands the node with the lowest f from a priority queue (the open set). The heuristic is the whole trick. If h never overestimates the true remaining cost, it is called admissible, and then A* is guaranteed to return an optimal path. A stronger property is consistency (monotonicity): h(n) <= cost(n, n') + h(n') for every edge; a consistent heuristic is always admissible and means a node never has to be reopened. On a grid where you can only move up, down, left and right, the Manhattan distance |dx| + |dy| is a good admissible heuristic; if diagonal moves are allowed you would use something else. If you set h(n) = 0 for every node, A* behaves exactly like Dijkstra's algorithm. A better heuristic means fewer expanded nodes, which is why A* is popular in game pathfinding and robot navigation. The main downside is memory: A* keeps every generated node in memory, which can be a problem on huge graphs.
