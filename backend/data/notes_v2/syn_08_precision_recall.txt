Accuracy can be misleading when classes are imbalanced: if only 1% of emails are spam, a model that never predicts spam is 99% accurate and completely useless. That is why we look at the confusion matrix, which counts true positives (TP), false positives (FP), true negatives (TN) and false negatives (FN). Precision = TP / (TP + FP) answers the question "of everything the model flagged as spam, how much really was spam?". Recall (also called sensitivity) = TP / (TP + FN) answers "of all real spam, how much did the model catch?". There is a trade-off between them controlled by the decision threshold: raising the threshold makes the model more careful, which usually increases precision and lowers recall; lowering it does the opposite. Which one matters more depends on the cost of mistakes. For a spam filter, precision matters because a false positive hides a real email. For cancer screening, recall matters because a missed case (false negative) is much worse than a false alarm. The F1 score combines both as the harmonic mean: F1 = 2 * precision * recall / (precision + recall). The harmonic mean punishes imbalance, so a model with precision 1.0 and recall 0.1 gets an F1 of only about 0.18.
