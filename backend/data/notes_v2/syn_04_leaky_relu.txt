Leaky ReLU is a small change to ReLU that fixes the dying ReLU problem. Instead of returning zero for negative inputs, it returns a small slope: f(x) = x for x > 0 and f(x) = alpha * x for x <= 0, where alpha is usually 0.01. Because the gradient for negative inputs is alpha instead of zero, a neuron that ends up with negative inputs can still receive updates and recover, so it never becomes permanently dead. For example, an input of -5 gives -0.05 with alpha = 0.01. PReLU (Parametric ReLU) takes the same idea but makes alpha a parameter that the network learns during training, so each channel can find its own slope. ELU (Exponential Linear Unit) uses alpha * (e^x - 1) for negative inputs, which is smooth and pushes mean activations closer to zero, at the cost of computing an exponential. GELU is a smooth activation that weights the input by the probability that a standard normal variable is smaller than it; it is the default activation in transformer models like BERT and GPT. In practice: start with ReLU, switch to Leaky ReLU if many neurons die, and use GELU if you are building a transformer.
