Binary search is the go-to algorithm when you need to find something in a sorted list very quickly. Instead of checking every single element from the beginning (which is called Linear Search), we use a divide-and-conquer strategy. We look at the middle element of the array. If the middle is exactly what we are looking for, we are done. If our target is smaller, we throw away the right half of the array and repeat the process on the left half. If it's larger, we focus on the right half. Because we halve the search space every single time, the average and worst-case time complexity is O(log n), which is incredibly fast compared to O(n) for linear search. When calculating the midpoint, it is often better to use 'low + (high - low) / 2' to avoid integer overflow issues that can happen in some languages with very large arrays. For example, if you have an array [1, 3, 5, 7, 9] and want to find 7, you start with the middle (5). Since 7 > 5, you look at the right side [7, 9], find the new middle (7), and you're done in just two steps.
