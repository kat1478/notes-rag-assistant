Read with care

  • Judge metrics come from an LLM judge (GPT-5.6 Luna) grading each answer against the dataset's expected key points and the retrieved context. Checked against 25 blind human labels: 84% agreement on correct vs. not, 84% on faithfulness; the judge is stricter than the human on both. "Answered" in the table only means a non-refusal.
  • Grounding split. When retrieval did not return the note that holds the answer, the correct grounded behaviour is to refuse — so those questions count as refusal tests, not answer tests.
  • Corpus v2 = the 11 original notes + 12 synthetic near-topic notes written by an LLM, frozen for benchmarking. Results are only comparable within one corpus.
  • Valid citation = the answer contains at least one [Source N] pointing to a chunk that was actually in the context.
  • Out-of-scope: 17 questions in v2 (5 unrelated, 12 near-topic traps where a related note exists but the asked fact does not); only 2 in v1. Small differences between models are still within noise.
  • Configuration: these runs used the original setup (English-only embeddings, prompt v1) so all models stay comparable. The app now runs multilingual embeddings and prompt v3, which raised Haiku's share of correctly answered questions from 68% to 94% — see the README.
  • Latency: local model on this machine's CPU vs. hosted models over the network — not the same hardware.
  • Cost from token usage × OpenRouter list prices at run time; local inference counted as $0.
